# Вариации дизайна сайтов (8 структур × 3 группы)

В этой папке — **24 готовых сайта**: для каждой группы экзамена сделано **8 разных
структурно-визуальных вариантов**. Это альтернативные «оболочки» одного и того же
приложения: можно выбрать любой понравившийся и задеплоить.

> Палитра, шрифты и изображения **не менялись** — они заданы по «Руководству по
> стилю» каждого варианта задания. Различаются только **структура страниц,
> компоновка, анимации и интерактивность**. Серверная логика, БД и весь функционал
> (регистрация/вход/заявки/админка/отзывы/слайдер) идентичны протестированной базе.

```
variants/
├── group_1/   (Конференции.РФ — серо-зелёная тема, Roboto)
├── group_2/   (Учусь.РФ — синяя тема, Inter)
└── group_3/   (Пассажирам.РФ — синяя тема, PT Sans)
        ├── v1_classic/
        ├── v2_sidebar/
        ├── v3_editorial/
        ├── v4_bento/
        ├── v5_minimal/
        ├── v6_glass/
        ├── v7_brutalist/
        └── v8_scroll/
```

## Восемь дизайн-направлений

| Вариант | Стиль | Чем отличается структурно |
|---------|-------|---------------------------|
| **v1_classic**   | Классический | Верхнее меню, градиентный hero, сетка карточек (базовый дизайн). |
| **v2_sidebar**   | Дашборд с боковым меню | Вертикальный навигационный рейл слева, контент-панели, метрики, таймлайн шагов. Скролл-спай по разделам. |
| **v3_editorial**  | Журнальная типографика | Крупные акцентные заголовки, асимметричные сплиты, нумерация секций, наезд изображений, параллакс. |
| **v4_bento**      | Bento-сетка | Модульные плитки разного размера (Apple-style), кластер hero-плиток, мозаика каталога, hover-tilt. |
| **v5_minimal**    | Швейцарский минимализм | Максимум воздуха, hairline-линии вместо теней, квадратные кнопки, индикатор прогресса чтения. |
| **v6_glass**      | Glassmorphism | Матовое стекло (blur), градиентные орбы, spotlight на карточках при наведении. |
| **v7_brutalist**  | Нео-брутализм | Толстые рамки, жёсткие смещённые тени, UPPERCASE, marquee-строка, «нажимающиеся» элементы. |
| **v8_scroll**     | Scroll-snap / журнал | Полноэкранные секции со scroll-snap, точки-навигация, прогресс скролла, горизонтальная карусель каталога. |

Все варианты адаптивны (десктоп + смартфон 390×844), сохраняют слайдер,
модальные окна, фильтры/сортировку/пагинацию админки и микроанимации.

## Как задеплоить выбранный вариант

Точно так же, как базовый проект (см. корневой `README.md`):

1. Скопируйте содержимое нужной папки варианта (например, `variants/group_1/v6_glass/`) в папку домена OpenServer.
2. В `.osp/project.ini` укажите свой домен.
3. Создайте БД в phpMyAdmin и впишите её имя в `db_config.php`.
4. Откройте сайт — таблицы и каталог создадутся автоматически. Админ: `Admin26` / `Demo20`.

## Техническая заметка

Каждый вариант = общее ядро (`bootstrap.php`, серверные страницы, `app.js`) +
сменный презентационный слой:

- `index.php` — структура лендинга,
- `static/style.css` — полная дизайн-система на CSS-переменных палитры,
- `static/variant.js` — доп. интерактив (грузится после `app.js`, не дублирует его).

Проверено: `php -l` по всем файлам без ошибок, сквозной сценарий
(регистрация → заявка → смена статуса → отзыв) проходит, в консоли браузера ошибок нет.
