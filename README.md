# проект 1 группы на дем экзамен

## **Инструкция по запуску**

1.  Скачать проект (зеленая кнопка code, Download zip)
2.  Заходим C:\OSPanel\home
3.  Создаем папку домена с названием своей фамилии в английском транслите, например - bondarev.local
4.  Перекидываем в только что созданную папку все из папки group_1_on_10.06
5.  Открываем папку .osp, далее открываем файл project.ini
6.  Меняем домен в [ ] на свою фамилию в английском транслите, например - [bondarev.local]
7.  Перезапускаем OSPanel
8.  Открываем PHPMyAdmin
9.  Заходим, пользователь - root, пароль - пустой
10. Слева сверху кликаем "Создать БД"
11. В поле имя базы данных пишем название бд (любое, рекомендую свою фамилию в английском транслите, например - bondarev)
12. Кликаем кнопку создать, закрываем phpmyadmin
13. Возвращаемся в папку с проектом
14. Открываем файл db_config.php
15. Меняем название базы данных в строке 'dbname=МЕНЯЕМ ЭТОТ ТЕКСТ' на то, которое вводили при создании бд на шаге 11
16. Перезапускаем OSPanel
17. Открываем проект в браузере
18. Если сайт открылся - все по кайфу, вы все сделали правильно. Если нет - значит вы где-то ошиблись, смотрите видео внимательнее.
19. Открываем файл index.php
20. На строке 176 меняем 'admin' и 'education' на те логин и пароль, которые написаны по заданию (Если они и так написаны правильно - НЕ ТРОГАТЬ)
21. Закрываем, обновляем сайт, пробуем зайти в админку по только что измененным данным
22. В папке домена которую создавали на шаге 3 создаем папку design, открываем
23. Открываем сайт, скриним каждую страницу сайта и вставляем скрины в папку design, называем их логически правильно (наприме, заскринили страницу входа - скрин назвали login_page.png)
24. Открываем PHPMyAdmin, ищем базу данных которую создавали на шаге 11, раскрываем дерево базы данных кликая на все +
25. Скриним полностью раскрытое дерево, скрин вставляем в папку проекта которую создавали на шаге 3, скрин называем db.png
26. Далее, все оставшееся время - меняем стили на сайте в файле style.css, который лежит в папке проекта по пути /static/style.css
27. Все
