# Проекты демонстрационного экзамена (09.02.07, 2026)

В репозитории три готовых проекта — по одному на каждый день экзамена. Все три
построены на **PHP 8.4 + MySQL 8.4**, запускаются на **OpenServer** последней
версии и закрывают все три модуля задания (проектирование БД, дизайн,
оптимизация).

| Папка               | Портал                                      | Тема                 | Вариант |
| ------------------- | ------------------------------------------- | -------------------- | ------- |
| `group_1_for_02.06` | **Конференции.РФ** — бронирование помещений | серо-зелёная, Roboto | В2      |
| `group_2_for_03.06` | **Учусь.РФ** — онлайн-курсы                 | синяя, Inter         | В5      |
| `group_3_for_04.06` | **Пассажирам.РФ** — курсы водителей         | синяя, PT Sans       | В3      |

Берёте папку нужной группы — внутри полностью самодостаточный сайт.

## Инструкция по запуску на OpenServer

> OpenServer последней версии (где папка **home** вместо domains и используется папка **.osp**).

1. Скачайте проект (зелёная кнопка **Code → Download ZIP**) и распакуйте.
2. Откройте папку OpenServer: `C:\OSPanel\home`.
3. Создайте папку домена с названием своей фамилии в транслите, например `bondarev.local`.
4. Скопируйте в неё **всё содержимое** папки нужной группы (например, из `group_1_for_02.06`) — так, чтобы `index.php` лежал прямо в `bondarev.local\`.
5. Откройте папку `.osp` → файл `project.ini`. В квадратных скобках замените домен на свой, например `[bondarev.local]`. Сохраните.
6. Перезапустите OpenServer.
7. Откройте **phpMyAdmin** (пользователь `root`, пароль пустой).
8. Слева сверху нажмите **«Создать БД»**, введите имя (рекомендуется фамилия в транслите, например `bondarev`), нажмите **Создать**.
9. В папке проекта откройте файл **`db_config.php`** и в строке `'dbname' => '...'` впишите имя только что созданной базы. Сохраните.
10. Перезапустите OpenServer и откройте сайт в браузере (`http://bondarev.local`).

> **Таблицы создаются автоматически** при первом открытии сайта — наполнять базу вручную не нужно. Каталог тоже заполняется сам.

11. Если сайт открылся и каталог отображается — всё настроено правильно.
12. Войдите в админку: ссылка **«Войти»**, логин `Admin26`, пароль `Demo20` (они уже заданы по варианту в `config.php`, менять не нужно).

### Логин и пароль администратора

По заданию: **`Admin26` / `Demo20`**. Заданы в файле `config.php` каждого проекта
(ключи `admin_login` / `admin_pass`). Менять не требуется.

## Что сдавать (скриншоты и материалы)

1. В папке домена создайте папку `design`.
2. Откройте сайт, сделайте скриншоты каждой страницы (главная, регистрация, вход, личный кабинет, оформление заявки, админка) и положите их в `design`, назвав по смыслу: `login_page.png`, `cabinet_page.png` и т. д.
3. В phpMyAdmin откройте свою БД, раскройте дерево таблиц (нажмите все «+»), сделайте скриншот полностью раскрытого дерева и сохраните его в корне проекта как `db.png`.
4. ER-диаграмма и SQL-схема уже готовы в папке `docs/` (`er-diagram.svg`, `database.sql`) — сохранить в корне проекта.

## Где что лежит (структура проекта)

```
group_X/
├── .osp/project.ini      ← домен для OpenServer (правится 1 раз)
├── db_config.php         ← подключение к БД (вписать имя базы)
├── config.php            ← тема, контент, каталог, статусы, данные админа
├── bootstrap.php         ← ядро: сессия, PDO, автосоздание таблиц, функции
├── index.php             ← главная (каталог, лендинг)
├── register.php          ← регистрация
├── login.php             ← вход (пользователь и администратор)
├── logout.php            ← выход
├── booking.php           ← оформление заявки
├── cabinet.php           ← личный кабинет (история, слайдер, отзывы)
├── admin.php             ← панель администратора
├── includes/             ← общие шапка и подвал
├── static/
│   ├── style.css         ← все стили (правьте для смены внешнего вида)
│   ├── app.js            ← интерактив (слайдер, модалки, анимации)
│   └── img/              ← изображения и слайды
└── docs/                 ← ER-диаграмма и SQL-схема для Модуля 1
```

**Внешний вид** меняется в `static/style.css` (цвета — в самом верху через
CSS-переменные, продублированы из `config.php`). **Тексты и каталог** — в `config.php`.
