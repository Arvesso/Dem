# Инструкция по выполнению демонстрационного экзамена

## Вариант 1 — Автосервис «АвтоМастер»

> Локальная разработка на OpenServer. Полное прохождение всех пяти задач вариативной части.

---

## TL;DR структура работы

1. Подготовить OpenServer — создать домен и базу данных
2. Распаковать WordPress и пройти мастер установки
3. Установить и настроить тему Sydney
4. Установить плагины из `media/plugins`
5. Настроить плагин кастомного пункта меню (изменить текст)
6. Настроить плагин обратного отсчёта (изменить дату + создать тестовую страницу)

**Параметры варианта:**

| Параметр | Значение |
|---|---|
| Домен сайта | `http://automaster.local/` |
| Логин администратора | `admin_auto` |
| Пароль администратора | `Service2025!` |
| Название сайта | АвтоМастер — автосервис |
| Тема | Sydney |
| Текст пункта меню | Раздел записи клиентов на техническое обслуживание |
| Целевая дата отсчёта | `2026-06-01T09:00:00+03:00` |

## Шаг 0. Подготовка OpenServer

### 0.1. Запуск

1. Запустить `Open Server x64.exe` (или x86) от имени администратора
2. В системном трее правый клик на флажке OpenServer → **Запустить**
3. Если флажок жёлтый или красный — проверить, не занят ли порт 80 (часто его занимают Skype, IIS, служба World Wide Web Publishing Service)

### 0.2. Создание домена

1. Открыть папку OpenServer → подпапку `domains`
2. Создать новую папку с именем `automaster.local`
3. В трее OpenServer: правый клик → **Перезапустить**

### 0.3. Создание базы данных

1. В трее OpenServer: правый клик → **Дополнительно** → **PhpMyAdmin**
2. Войти: логин `root`, пароль пустой
3. Слева нажать **Создать БД** → имя `wp_automaster`, кодировка `utf8mb4_unicode_ci` → **Создать**

## Шаг 1. Задача 17 — Установка WordPress

### 1.1. Распаковка архива

1. Из папки `media` взять архив WordPress (например, `wordpress-6.x.zip`)
2. Распаковать его в `domains/automaster.local/` так, чтобы файлы `wp-config-sample.php`, `wp-login.php`, `index.php` лежали **прямо в корне** домена, а не во вложенной папке `wordpress`

**Структура должна получиться такой:**

```
domains/automaster.local/
├── wp-admin/
├── wp-content/
├── wp-includes/
├── index.php
├── wp-config-sample.php
└── ... (остальные файлы WP)
```

### 1.2. Запуск установщика

1. В браузере открыть `http://automaster.local/`
2. Выбрать язык **Русский** → **Продолжить**
3. На следующей странице → **Вперёд!**
4. Заполнить поля подключения к БД:
   - Имя базы данных: `wp_automaster`
   - Имя пользователя: `root`
   - Пароль: *(оставить пустым)*
   - Сервер базы данных: `localhost`
   - Префикс таблиц: `wp_`
5. **Отправить** → **Запустить установку**

### 1.3. Создание администратора

Заполнить форму:

- Название сайта: **АвтоМастер — автосервис**
- Имя пользователя: `admin_auto`
- Пароль: `Service2025!`
- Поставить галочку **«Подтвердите использование слабого пароля»** (WordPress покажет это предупреждение — это нормально, пароль должен быть именно таким по заданию)
- Email: любой, например `admin@automaster.local`
- Снять галочку **«Видимость для поисковых систем»** (для локальной разработки)

Нажать **Установить WordPress**.

### 1.4. Проверка

- Открыть `http://automaster.local/` — должна загрузиться главная страница сайта
- Открыть `http://automaster.local/wp-admin/` — должна открыться страница входа в админку
- Войти с логином `admin_auto` и паролем `Service2025!`

**Закрыты критерии:** 17.1, 17.2, 17.3, 17.4

## Шаг 2. Задача 18 — Установка темы Sydney

### 2.1. Установка темы

1. Войти в админку (`/wp-admin`)
2. Перейти в **Внешний вид** → **Темы**
3. Нажать **Добавить новую тему** → **Загрузить тему**
4. Выбрать ZIP-архив `sydney.zip` из папки `media/themes/`
5. Нажать **Установить**
6. После установки нажать **Активировать**

> Если после активации темы появится уведомление о рекомендуемых плагинах — его можно закрыть, устанавливать дополнительные плагины не требуется.

### 2.2. Замена превью темы

1. Открыть папку темы в файловой системе: `domains/automaster.local/wp-content/themes/sydney/`
2. Внутри уже есть файл `screenshot.png` — это стандартное превью темы
3. Заменить его на изображение из `media/screenshots/`
4. **Важно:** имя файла должно остаться `screenshot.png`

Рекомендуемый размер превью — 1200×900 px. Если изображение другого размера, WordPress всё равно его покажет, но обрежет по краям.

> После замены превью в админке может показываться старая закэшированная картинка. Открыть страницу тем в режиме инкогнито или нажать Ctrl+F5 — подгрузится новое изображение.

### 2.3. Проверка стилей и изображений

1. Открыть `http://automaster.local/` в браузере
2. Нажать F12 → перейти на вкладку **Network** (Сеть)
3. Перезагрузить страницу (Ctrl+R)
4. Убедиться, что все файлы `.css` и изображения отдаются со статусом **200** (не 404)

**Закрыты критерии:** 18.1, 18.2, 18.3, 18.4

## Шаг 3. Задача 19 — Установка плагинов из media

1. В админке перейти в **Плагины** → **Добавить плагин** → **Загрузить плагин**
2. Для каждого ZIP-архива в папке `media/plugins/`:
   - Нажать **Выберите файл** → указать ZIP
   - Нажать **Установить**
   - После установки нажать **Активировать плагин**
3. После активации всех плагинов открыть главную страницу сайта и админку
4. Убедиться, что сайт работает без фатальных ошибок (нет «белого экрана смерти»)

> Если после активации какого-то плагина сайт перестал открываться — деактивировать последний установленный плагин через файловую систему: переименовать папку плагина в `wp-content/plugins/` (например, добавить `_disabled` к имени). После этого сайт снова заработает.

**Закрыты критерии:** 19.1, 19.2, 19.3

## Шаг 4. Задача 20 — Настройка плагина кастомного пункта меню

Плагин уже установлен и активирован в Шаге 3 (он лежал в `media/plugins`). Теперь нужно изменить текст, который выводится на странице пункта меню.

### 4.1. Открытие файла плагина

1. В файловой системе перейти в `domains/automaster.local/wp-content/plugins/custom-admin-menu/`
2. Открыть файл `custom-admin-menu.php` в любом редакторе кода (VS Code, Notepad++, Sublime Text)

### 4.2. Изменение текста

В коде найти строку с маркером `// TEXT_TO_REPLACE`:

```php
// TEXT_TO_REPLACE — замените текст ниже в кавычках на текст из задания
$page_text = 'Текст по умолчанию (замените на текст из задания)';
```

Заменить значение переменной `$page_text` на текст из задания:

```php
// TEXT_TO_REPLACE — замените текст ниже в кавычках на текст из задания
$page_text = 'Раздел записи клиентов на техническое обслуживание';
```

Сохранить файл (Ctrl+S).

### 4.3. Проверка

1. Открыть админку WordPress (обновить страницу, если она уже открыта)
2. В левом боковом меню должен появиться новый пункт **«Кастомный раздел»**
3. Кликнуть на этот пункт — откроется страница с заголовком и текстом:
   > Раздел записи клиентов на техническое обслуживание
4. Убедиться, что сайт продолжает открываться без ошибок (фронт + админка)

> Если после правки появилась ошибка PHP — внимательно проверить, не была ли случайно удалена кавычка или точка с запятой. Самая частая ошибка — кавычка в самом тексте, которая закрывает строку раньше времени. Если в тексте есть апостроф, нужно либо экранировать его (`\'`), либо использовать двойные кавычки вокруг строки.

**Закрыты критерии:** 20.1, 20.2, 20.3, 20.4

## Шаг 5. Задача 21 — Настройка плагина обратного отсчёта

Плагин уже установлен и активирован в Шаге 3. Нужно изменить целевую дату и создать тестовую страницу с шорткодом.

### 5.1. Изменение целевой даты

1. В файловой системе перейти в `domains/automaster.local/wp-content/plugins/countdown-timer/`
2. Открыть файл `countdown-timer.php` в редакторе кода
3. Найти строку с маркером `// TARGET_DATE`:

```php
// TARGET_DATE — замените значение в кавычках на дату из задания (формат ISO 8601)
const COUNTDOWN_TARGET = '2026-01-01T00:00:00+03:00';
```

4. Заменить значение константы на дату из задания:

```php
// TARGET_DATE — замените значение в кавычках на дату из задания (формат ISO 8601)
const COUNTDOWN_TARGET = '2026-06-01T09:00:00+03:00';
```

5. Сохранить файл (Ctrl+S)

### 5.2. Создание тестовой страницы

1. В админке перейти в **Страницы** → **Добавить новую**
2. В поле заголовка ввести: **До открытия**
3. В содержимое страницы добавить шорткод `[countdown]`:
   - **В блочном редакторе (Gutenberg):** нажать «+» → найти блок **Шорткод** → вставить `[countdown]`
   - **В классическом редакторе:** просто написать `[countdown]` в тексте
4. Нажать **Опубликовать**
5. После публикации нажать **Просмотреть страницу**

### 5.3. Проверка

На открывшейся странице должен отображаться таймер в формате `ДД:ЧЧ:ММ:СС`. Например:

```
07:14:23:47
```

Подождать несколько секунд — значение должно меняться **без перезагрузки страницы** (тикать каждую секунду).

> Если таймер показывает «Загрузка…» и не меняется — открыть F12 → **Console**, посмотреть ошибку. Скорее всего, путь к `countdown.js` сломан. Проверить, что файл `countdown.js` действительно лежит в папке плагина рядом с PHP-файлом.

> Если таймер показывает «Ошибка даты» — проверить формат константы `COUNTDOWN_TARGET`. Он должен быть в формате ISO 8601 с таймзоной: `ГГГГ-ММ-ДДTЧЧ:ММ:СС+03:00`.

**Закрыты критерии:** 21.1, 21.2, 21.3, 21.4, 21.5, 21.6

## Типовые проблемы и решения

### OpenServer не запускается

**Симптом:** флажок в трее красный, сайт не открывается.

**Решение:**
- Проверить, не занят ли порт 80. В трее: правый клик → **Просмотр логов** → искать `Address already in use`
- Если порт занят — в **Настройки** OpenServer изменить HTTP-порт на 8080. Тогда домен будет открываться по `http://automaster.local:8080/`

### «Ошибка установления соединения с базой данных»

**Симптом:** при установке WordPress показывается эта ошибка.

**Решение:**
- Проверить, что в трее OpenServer запущен MySQL/MariaDB (флажок зелёный)
- Имя пользователя БД по умолчанию — `root`, пароль — **пустой**. Многие пытаются ввести что-то наугад
- Имя базы данных должно точно совпадать с тем, что создано в PhpMyAdmin

### Превью темы не обновляется

**Симптом:** в **Внешний вид → Темы** показывается старое превью.

**Решение:**
- Браузерный кэш. Нажать Ctrl+F5 на странице тем
- Или открыть админку в режиме инкогнито

### Шорткод выводится как текст `[countdown]`

**Симптом:** на странице вместо таймера видна строка `[countdown]`.

**Решение:**
- Проверить, что плагин активирован (**Плагины → Установленные**)
- Шорткод должен быть в обычном блоке текста или в блоке «Шорткод», но не в блоке HTML или Code (там WP не парсит шорткоды)

### Таймер показывает «Загрузка…»

**Симптом:** на странице видно «Загрузка…», значение не меняется.

**Решение:**
- F12 → **Console** → посмотреть ошибку
- Скорее всего, файл `countdown.js` не загрузился. Проверить, что он лежит в `wp-content/plugins/countdown-timer/countdown.js`

### Лимит загрузки превышен

**Симптом:** при загрузке ZIP появляется ошибка «Размер загруженного файла превышает upload_max_filesize».

**Решение:**
1. В трее OpenServer: правый клик → **Дополнительно** → **Конфигурация** → **PHP-8.x**
2. Найти и увеличить значения:
   ```ini
   upload_max_filesize = 64M
   post_max_size = 64M
   ```
3. Сохранить файл и перезапустить OpenServer
